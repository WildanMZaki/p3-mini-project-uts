# Karhutla Lapor

Aplikasi web komunitas untuk pelaporan dan pemantauan indikasi kebakaran hutan dan lahan (Mini Project Proyek 3 — Kasus B).

## Environment

- PHP 8.3+
- Composer 2
- MySQL / MariaDB
- Node.js 20+

## Instalasi Singkat

```bash
composer install
cp .env.example .env
php artisan key:generate
php artisan migrate
npm install
php artisan serve
```

Dokumentasi lengkap (konfigurasi database, seeding, dan akun demo) akan dilengkapi seiring pengembangan.
